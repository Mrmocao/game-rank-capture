# 全字段采集映射说明

22-field-collection-mapping.csv包含201行：原有120个原子字段逐项覆盖，加上81个游戏档案展示字段。后者是产品视图投影，不是再新增81个独立采集指标。

每行定义数据获得类别、可选来源ID、默认频率、关键口径、缺失处理与证据要求。多个source_ids表示按平台与准入条件选择的替代/补充路径，不表示每个来源都提供该字段，也不表示跨来源数值可以合并。

PUBLIC_*并不承诺完全自动：仅在该来源字段通过PoC和准入后开启。PUBLIC_SAMPLE是可见样本，不能称全量；LICENSED_ESTIMATE须采购确认且始终展示“估计”；INTERNAL_ONLY不属于公网可得范围；AI_WITH_*只处理有使用依据的输入并产生可审查结论。

reference_atomic_key用于说明主要上游语义，并非数据库一对一字段绑定。例如档案“包体大小”属于版本档案扩展属性，“留存”属于内部测试结果，“制作工期”属于基于团队能力的工程估算。Java开发时应建立明确类型，不把所有属性塞进一个无约束JSON字段。

所有字段默认遵循平台实体、市场、适用版本、observed_at、available_at、来源、使用策略和证据定位。不存在/未采集/来源不支持/没有权限/来源故障/已过期/有冲突分开；AI不得将unknown替换为看似合理的数字。
