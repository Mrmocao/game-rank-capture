## 2. 关键交互约定

产品详情右侧抽屉分“产品概览/平台与历史/玩家声音/推荐依据/选用记录”。同款跨平台展示多条原榜排名，不创建综合名次；混变平台版本明确标“关联参考”。在周报打开产品时使用报告截止日；普通列表打开时使用当前日期。

日期可指定任意日，原型仅有2026-10-19、22、25、28四个示例日期。其他日期显示无快照，不能回退到最新。22日抖音为缺失示例，不等于未上榜。推荐分析和玩家声音样例仅25日以后有值，之前不回填。生产系统历史查询按版本有效期处理身份、类型和变现等变更。

产品筛选支持关键词、平台、地区、候选状态。按名次排序必须选择单平台/国家/榜单；未选定时给出明确提示。产品库“全部”含观察池和不匹配关联样本，但仅通过资格的对象称正式候选。

评价卡显示时间、样本范围、分子/分母；主题可下钻，负面事件可直接查看对应摘录。证据弹窗有原始链接/引用位置，缺真实来源时明确无来源，不能生成看似真实链接。列表中的少量摘录不能被当作聚合指标分母。

修改研究权重即时试算，合计非100%则禁止保存和生成。已保存周报冻结结果；再改配置只影响下次生成。同产品可新建多条选用记录，每条独立更新；空负责人不可保存，完成日期不可早于开始或选用日期。

所有空态应说明缺数据、缺权限、未接入、未命中或历史不足；避免统一显示0。操作完成有反馈，抽屉支持Escape和返回触发点；页面窄屏保留可滚动表格，不把关键列缩至不可读。

## 3. 每个环节的AI职责

| 环节 | AI适合做什么 | 固定约束与退出路径 |
| --- | --- | --- |
| 信息范围 | 发现新字段/玩法标签/同义词，建议补证方向 | 输出建议，不自行增加付费来源或无限扩范围 |
| 内容理解 | 从授权材料提取实体、版本、玩法、变现线索 | 字段须带引用；原文没有的值为unknown |
| 身份关系 | 给出跨平台同款/相似玩法候选及证据 | 不确定时不自动合并；保留可撤销关系 |
| 玩家声音 | 多语言翻译、方面情感、主题聚类与痛点 | 原文保留，歧义可弃权；不把AI摘要作为第二个独立来源 |
| 事件解释 | 将热点、更新、投放和反馈关联成待验证假设 | 不因时间相近就宣称因果，不确认刷量指控 |
| 机制和制作 | 拆解核心循环、内容供给、提出最小实验 | 区分广告与实机；成本范围注明团队假设 |
| 推荐评估 | 依据引用提出分档、机会和反对理由 | 资格、数值计算、限额由规则执行，不能被自然语言覆盖 |
| 周报表达 | 把冻结的事实/决策写成可读卡片 | 不添加没有证据的新事实；引用自动检查 |
| 反馈学习 | 比较预测与实际、提出规则改进 | 先离线评估再发布新版本，不偷偷修改旧报告 |

每次AI分析保存：任务类型、输入证据ID及hash、模型标识、提示词/规则/分类体系版本、结构化输出、失败/弃权原因、执行时间、费用摘要和人工纠正。检索得到的内容视为数据，不作为工具指令；模型仅能使用允许字段和工具。

支持按任务配置模型、最大材料长度、抽样上限、预算、超时、降级和复核策略。一个模型故障不影响榜单快照和手工填报。AI的“置信度”只作为模型自评信息，不能替代样本覆盖、真实验证或确定性资格检查。

## 4. 原型与正式系统的边界

| 项目 | 本次可操作（基础页面、V2.2与历史对照分开） | 正式系统待开发 |
| --- | --- | --- |
| 页面/导航/筛选/详情 | 已实现 | 接API、账号和权限 |
| 日期和平台排名 | 4个日期的虚构夹具、缺失态、独立排名 | 实际每日快照和真实市场数据 |
| 评价与舆情 | 假评论筛选、方法说明、事件下钻 | 抽样、原文保存、真实AI与指标计算 |
| 信息范围 | 10域/60字段组浏览、搜索、范围草稿 | 原子字段配置、来源覆盖状态、审计 |
| 推荐 | V2.2按18例计算范围、分层、补证与11种缺失/故障场景；V2.1保留对照 | 真实证据校验、分轨分市场组合、内部结果回测 |
| 周报 | V2.2输入、未知状态、范围、层级、动作冻结与JSON导出 | 服务端任务、完整证据快照、历史回放 |
| 选用 | 浏览器内多人记录、状态/日期/反馈 | 共享数据库、修改历史、协作权限 |
| 采集、AI、定时任务 | 未启用 | 在后续接入阶段实现 |

不能把原型的固定分数、固定门槛、模拟来源或浏览器存储复制成生产逻辑。原型没有发起购买或对外推送。

## V2.2 本次新增的可操作界面

每周精选有“本周推荐 / 缺失数据试验 / 容错规则与依据”，另有V2.1历史对照入口。试验台可选择18个虚构案例和11种全队列情景，对单项设为未采集、过期、冲突、无权限或恢复原始有效样例。实时展示该产品范围和层级，并可查看整期名单。

结果页同时保留验证清单、线索、未入选和暂缓理由。详情展示六维上下界、权重贡献、已知限制、补证影响上界。配置中可改六维权重、名额、探索名额、工期预算、重点覆盖和范围宽度；无效配置阻止保存。保存周报冻结本地完整输入/结果，改变场景不改旧快照。

覆盖百分比不叫准确率；区间不叫成功率。试验台的“恢复”是恢复虚构夹具，不是启动采集。“仅保留榜单”仅指软分析输入，已核实的身份/IAA/实机及已知约束仍保留。“有效缓存”模拟适用于原截止窗口的已存证据，不实现后台缓存。

生产页面还应按运行展示来源异常、重试、各组织权限和服务器修订；这些未在静态原型中接通。完整规则见14，实测边界见16。


## V2.3 单款档案覆盖条款

当前单款游戏信息设计以17、18、19章为准：12信息域、81展示字段、8分区，平台/市场/版本/截止时间独立；来源事实与AI草案分别保存。完整资料量不等于推荐分，缺失和新反证不能被填补文案掩盖。V2.2推荐公式与分层规则保持不变。
