# V2.3 原型范围与验证记录

日期：2026-10-30；档案版本2.3.0，精选算法保持2.2.0。

## 已实现的原型能力

- 产品库：跨平台独立名次、参考平台资格、资料量与缺口、筛选、分页、CSV导出。
- 单款游戏：12信息域、81字段、8分区；平台市场切换、指定历史日、详情深链接、证据历史、缺失/冲突/过期显示。
- 证据与补全：字段搜索/状态筛选、按缺口生成并去重任务、负责人和进展填报、材料提交待复核；全部仅保存在本地浏览器。
- 选用记录：多负责人独立记录，参考平台、状态、日期与说明；当前协作记录不冒充历史市场快照。
- 导出：档案JSON包含schema版本、虚构标记、历史范围和独立当前协作区。
- 市场概览同步采用新档案的资格与资料量，不再使用旧固定机会分宣称可推荐数量。

## 自动验证

新增18项档案状态测试：跨平台IAA差异、冲突生效时间、历史防泄漏、更新后有效核查、旧版本失效、到期失效、跨地区评价隔离、无快照仍有档案、历史最佳范围、抖音缺失、分母口径、0与未知、AI不得提升资格、评价分母、补全任务幂等、多负责人、非法参数、输入不变性。

本轮执行71项Node测试全部通过（档案18、V2.1算法22、V2.2算法31）；既有20项基础领域检查通过。语法检查和git diff --check通过。算法测试用于防回归，不代表市场回测或真实成功率。

## 未实现 / 明确限制

没有Java服务、MySQL、账号/租户权限、真实采集、实际AI调用、供应商采购、定时周报。没有真实实机截图/视频；结构图明确标示意。材料复核状态和API仅是产品契约，原型不把提交材料自动转成事实。

V2.3档案和V2.2精选测试集未自动打通；两者通过设计契约衔接。基础页面中的旧舆情列表为V2演示数据，单款档案评价使用独立的平台市场夹具。没有真实下载、留存、收入或ROAS估计。

原型以日粒度和固定样例日期展示历史，生产需时区、时间戳、来源修订、身份版本和权限裁决。暂不支持任务人员权限、材料上传、服务端多人并发和消息提醒。
