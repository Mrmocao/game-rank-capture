## V2.2 容错验收目标

以下为产品/后端目标，不表示全部生产能力已实现；原型实测见16。

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| AC-59 | 玩家样本未取得 | P=[0,100]，其他维继续；允许条件推荐 |
| AC-60 | A/O均缺失 | 覆盖80%；其余证据满足时仍可重点验证 |
| AC-61 | 无成本或成本跨预算 | 范围反映未知/情景，先估算或缩范围 |
| AC-62 | 已确认成本下界超预算后来源失效 | 保持暂缓，不能用unknown解除 |
| AC-63 | IAA未知 | 保留线索和行动，不正式计纯IAA合格项 |
| AC-64 | 全部分析数据缺失 | 每个已知候选有诊断与行动，不输出确定名次 |
| AC-65 | 没有候选 | 输出来源恢复/导入任务，不编造游戏 |
| AC-66 | 缺部分榜单日期 | 完整14天分母求界，不只用已采日平均 |
| AC-67 | 榜单全部缺失 | 只能用已登记并验证的需求协议替代；D/M不伪造 |
| AC-68 | 同窗口有效缓存与来源失败 | 使用原始日期材料，结论可保持；附健康状态 |
| AC-69 | 过期、冲突、无权限 | 不同状态可追踪，当前计算按未知 |
| AC-70 | 10条样本且口径可比 | 可条件推荐；覆盖和区间精度分别展示 |
| AC-71 | 多个缺口影响同一来源 | D/M补证合并，不重复列采集任务 |
| AC-72 | 仅有条件推荐 | 可组成整期清单；探索名额不是条件推荐总数限制 |
| AC-73 | 合格验证数为0 | 仍能冻结线索、暂缓、补证报告 |
| AC-74 | 参数无效或探索名额超过总数 | 禁止生成新名单/保存，旧报告保留 |
| AC-75 | 单条坏记录或ID重复 | 隔离坏记录；重复双方待核实，其他记录继续 |
| AC-76 | 补数据后重算 | 生成新修订；旧范围/输入/行动不变 |
| AC-77 | 新增负面信息 | 可降低优先级或转暂缓，不能强制升分 |
| AC-78 | 不同市场/窗口/方案 | 分队列计算；不直接混总分 |
| AC-79 | 输入覆盖100%但样本小 | 不得称准确率100%或高置信度 |
| AC-80 | 混合范围含Wilson和情景 | 不得称整体95%区间或成功概率 |
