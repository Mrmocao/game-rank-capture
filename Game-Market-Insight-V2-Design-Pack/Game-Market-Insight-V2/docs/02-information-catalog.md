# 信息范围与字段目录

本版定义10个信息域、60个展示字段组、120个原子字段；另有通用来源/时间/口径/覆盖/权限元数据。这是需求目录，不是已接入字段统计。CSV可供产品和开发继续维护。

## 产品身份与生命周期

粒度：产品/平台版本。用途：去重与生命周期。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 稳定外部ID `external_id` | 文本 | 不能以名称作为唯一键 |
| 名称与别名 `canonical_name` | 文本数组 | 含历史名称及生效期 |
| 平台 `platform` | 枚举 | 平台版本粒度 |
| 发行/可用市场 `market` | 国家码 | 可用市场不等于玩家国籍 |
| 语言 `locale` | 语言码 | 区分商店语言和正文语言 |
| 开发主体 `developer` | 实体引用 | 来源展示名与归一主体分别存 |
| 发行主体 `publisher` | 实体引用 | 不能默认开发商即发行商 |
| 实际首次上线 `release_at` | 时间 | 无法证明时null |
| 系统首次观察 `first_seen_at` | 时间 | 不是实际上线时间 |
| 版本与更新日志 `version_history` | 事件数组 | 保存版本和有效期 |
| 上架/下架/暂停状态 `availability` | 枚举 | 缺失不等于下架 |
| 跨平台同款关系 `cross_platform_relation` | 证据关系 | 区分同款与相似机制 |

## 榜单与市场表现

粒度：平台版本+榜单+统计日。用途：需求验证与变化。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 榜单及定义版本 `chart_id` | ID | 玩家热度/买量榜类型分离 |
| 原始榜单名次 `rank` | 整数 | 缺失为null，不填101 |
| 快照覆盖范围 `chart_coverage` | 对象 | Top N、完整率、缺口 |
| 首次观察上榜日 `first_chart_seen` | 日期 | 非历史首次上榜断言 |
| 进入/离开监测范围 `entry_exit_events` | 事件数组 | 仅完整快照可判离开 |
| 有效观察日数 `observed_days` | 天 | 同源同口径 |
| Top100有效日数 `top100_days` | 天 | 缺失日不补值 |
| 单榜名次变化 `rank_change` | 位 | 当前与比较窗口明确 |
| 下载估计 `download_estimate` | 区间 | 估算方法/供应商必填 |
| 活跃估计 `active_estimate` | 区间 | DAU/MAU窗口分开 |
| 单市场趋势 `market_trend` | 派生序列 | 不直接平均跨榜名次 |
| 口径/覆盖断点 `coverage_break` | 事件 | 来源或榜单定义变更 |

## 玩家评价与体验

粒度：评价内容/内容修订。用途：真实体验与需求。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 来源显示评分 `rating_display` | 数值+尺度 | 地区/时间和算法口径保留 |
| 来源评分数 `rating_count` | 计数 | 不等同文字评价数 |
| 来源文字评价数 `review_count` | 计数 | 不等同实际采集数 |
| 星级分布 `star_distribution` | 1～5计数 | 无分布不估算好评率 |
| 原文/授权摘录 `review_text` | 文本 | 记录可保存范围 |
| 评论编辑与版本 `review_revision` | 事件数组 | 编辑不算新玩家 |
| 发布/更新时间 `review_date` | 时间 | 与采集时间分开 |
| 评论所述游戏版本 `game_version` | 文本 | 未知不猜测 |
| 整体情感 `sentiment` | 枚举 | 正/负/中/混合/无法判断 |
| 方面情感 `aspect_sentiment` | 多标签 | 一条可多方面、不同倾向 |
| 问题与期待 `player_need` | 带引用文本 | 事实陈述与建议分开 |
| 抽样/分母/偏差 `sample_coverage` | 对象 | 来源总量和采集量分开 |

## 社区舆情与讨论

粒度：内容/来源窗口/事件。用途：热度解释与风险。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 讨论载体与类型 `content_type` | 枚举 | 帖/视频评论/论坛/直播讨论等 |
| 提及与去重簇 `mention_cluster` | ID | 同源转载独立记录关系 |
| 来源内去标识作者 `source_author` | ID | 不跨平台猜身份 |
| 点赞/评论/转发观测值 `interaction_snapshot` | 计数+时间 | 累计值不是日新增 |
| 根来源族 `source_family` | ID | 独立验证去重 |
| 商业内容已知标记 `paid_label` | 枚举 | 未知不等于自然传播 |
| 讨论主题 `topic` | 标签数组 | 分类体系版本可追溯 |
| 固定范围提及变化 `mention_growth` | 比例 | 基期0与覆盖断点特殊处理 |
| 负面率变化 `negative_shift` | 百分点 | 两期样本分母并列 |
| 舆情事件 `event` | 实体引用 | 影响版本和时间范围 |
| 疑似异常信号 `suspected_anomaly` | 标签+依据 | 非刷量定论 |
| 事件复核结论 `event_review` | 状态+引用 | 不能只有AI定性 |

## 玩法与产品结构

粒度：平台版本/试玩记录。用途：可实现性与玩法家族。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 核心操作循环 `core_loop` | 结构化步骤 | 实际玩法与广告分别描述 |
| 操作方式 `controls` | 标签 | 触摸/拖拽等 |
| 规则与限制 `constraints` | 文本+引用 | 空间/时间/资源等 |
| 胜负与失败条件 `win_fail` | 对象 | 明确实机证据 |
| 单局时长 `session_duration` | 区间 | 观察样本与关卡 |
| 首局学习成本 `onboarding` | 记录 | 试玩条件必填 |
| 难度曲线 `difficulty` | 记录 | 局部观察不代表全部关卡 |
| 关卡/内容供给方式 `level_supply` | 标签 | 模板/手工/生成及未知 |
| 外围系统 `meta_systems` | 数组 | 升级/社交/活动等 |
| 表现与技术依赖 `art_tech_cost` | 评估 | 区分观察与成本假设 |
| 截图/实机/视频入口 `gameplay_media` | 证据引用 | 广告视频单独标类型 |
| 素材与玩法一致性 `ad_play_match` | 结论+引用 | 至少对比两类材料 |

## 广告素材与投放

粒度：创意变体+渠道+市场。用途：可测卖点与投放线索。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 素材与变体ID `creative_id` | ID | 近似素材归簇但保留变体 |
| 投放渠道/版位 `ad_platform` | 标签 | 来源允许的粒度 |
| 投放市场 `ad_market` | 国家码 | 未知不按语言猜测 |
| 广告主/投放主体 `advertiser` | 实体 | 与研发主体分开 |
| 形式/时长 `creative_format` | 标签+秒 | 图/视频/试玩等 |
| 前段钩子与卖点 `hook` | 标签+引用 | AI可分析但保留片段定位 |
| 首次/末次观察 `creative_first_last` | 时间 | 不是实际完整投放周期 |
| 观察活跃天数 `creative_active_days` | 天 | 缺失日不当停止 |
| 落地产品/版本 `landing_version` | 引用 | 防止同名归错 |
| 素材新增/活跃数量 `creative_volume` | 计数 | 素材数不等于预算 |
| 花费/曝光估计 `spend_impression_estimate` | 区间 | 需合法授权来源及方法 |
| 可复用创意假设 `creative_test_hypothesis` | 假设+依据 | 不能推断真实CTR/CPI |

## 变现与经营线索

粒度：版本+市场+有效期。用途：IAA资格与经济验证。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 变现模式 `monetization_mode` | 枚举 | 纯IAA/混合/内购/未知 |
| 广告变现证据 `ad_evidence` | 引用 | 说明可见场景 |
| 广告形式 `ad_formats` | 数组 | 激励/插屏/横幅等 |
| 广告触发与频次 `ad_trigger` | 试玩记录 | 条件和样本明确 |
| 内购/付费证据 `iap_evidence` | 引用/未知 | 去广告付费也属于内购 |
| 排除内购依据 `no_iap_basis` | 多项引用 | 未发现按钮不是充分证明 |
| 资格有效期 `qualification_window` | 起止时间 | 新版本需复核 |
| 奖励兑现与打断 `ad_experience` | 体验记录 | 用户观点与实测区分 |
| 收入估计 `revenue_estimate` | 区间 | 来源估计与实际分开 |
| 自有测试eCPM `internal_ecpm` | 金额/千次 | 只用内部授权数据 |
| 自有LTV/ROI `internal_ltv_roi` | 金额/比例 | 队列、成本口径、回收期 |
| 经营未知项 `economics_unknowns` | 数组 | 不从排名推断收入 |

## 同类竞争与供给

粒度：玩法家族+市场+窗口。用途：供需与差异空间。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 玩法家族 `family_id` | ID | 按机制，非仅视觉相似 |
| 对照竞品集合 `peer_set` | ID数组 | 纳入条件可追溯 |
| 同类新增观察 `peer_new` | 计数 | 首次观察不等首发 |
| 同类头部成员 `peer_head` | 集合 | 单市场/同口径 |
| 同类持续表现 `peer_persistence` | 序列 | 不只选成功者 |
| 下滑/退出成员 `peer_decline` | 集合 | 缺失与退出分开 |
| 同类供给密度 `supply_density` | 代理指标 | 监测范围内，不称全市场总量 |
| 供给/表现集中度 `concentration` | 派生值 | 同口径且覆盖足够才算 |
| 机制/人群/表现差异 `differentiation` | 矩阵 | 需证据 |
| 竞品未满足需求 `unmet_need` | 引用集合 | 多条独立反馈支持 |
| 跨平台机会假设 `platform_gap` | 假设 | 不同市场验证不能直接迁移 |
| 失败案例与原因 `failed_lessons` | 记录 | 失败原因可能未知，不随意归因 |

## 传播、搜索与外部事件

粒度：内容/词/事件窗口。用途：趋势成因与扩散。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 搜索词与同义词 `search_term` | 词表 | 歧义词需限定实体 |
| 来源搜索指数 `search_index` | 原生单位 | 不同服务指数不可直接相加 |
| 同口径搜索变化 `search_change` | 比例 | 覆盖断点和基期0处理 |
| 创作者内容 `creator_content` | 引用 | 内容定位与发布日期 |
| 来源展示触达 `creator_reach` | 计数/估计 | 播放不等独立玩家 |
| UGC玩法内容 `ugc` | 引用 | 与商业内容标签分开 |
| 媒体报道 `news` | 引用 | 转载同源去重 |
| 编辑推荐/平台活动 `platform_feature` | 事件 | 活动曝光不等长期需求 |
| 季节/节日关联 `seasonality` | 假设+时间 | 不自动认定因果 |
| 外部事件 `external_event` | 引用 | 区分事实与影响推断 |
| 跨市场传播线索 `cross_market_spread` | 时间关系 | 先后不等因果 |
| 热度驱动假设 `driver_hypothesis` | 引用+反证 | 保留其他解释 |

## 内部能力与验证反馈

粒度：团队+选用记录+实验。用途：个性化与推荐复盘。

| 字段 | 类型/单位 | 口径与约束 |
| --- | --- | --- |
| 团队技能与资产 `team_profile` | 对象 | 按研究方案版本保存 |
| 原型人力/时间预算 `prototype_budget` | 区间 | 与上线版本预算分开 |
| 选用与负责人 `selection` | 多记录 | 多人互不覆盖 |
| 状态/日期/备注 `progress` | 记录 | 未选为派生状态 |
| 参考目标平台版本 `reference_version` | 引用 | 不能只记统一产品名 |
| 实验假设与继续条件 `test_hypothesis` | 对象 | 测试前明确 |
| 实验版本/人群/渠道 `test_context` | 对象 | 可比性元信息 |
| 测试样本及观察窗 `test_sample` | 计数+窗口 | 人数、内容量不可混用 |
| 结果和失败原因 `test_result` | 记录 | 选用和上线不等于成功 |
| 实际人力/费用 `cost_actual` | 数值+单位 | 与估算分开 |
| 推荐有用/错误/缺口 `recommendation_feedback` | 反馈 | 不能只有点击率 |
| 规则改进与回测 `calibration` | 版本+结果 | 避免事后泄漏与自动改旧规则 |
