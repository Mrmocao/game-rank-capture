## 使用边界

全部产品、评论、范围、协议和推荐均为虚构演算。未接真实数据、AI、Java后台、MySQL、缓存服务或定时任务。120字段是目标信息目录，不代表已验证可采集。权重和阈值是可校准设计，不是训练出的成功概率；计算测试通过不证明爆款发现效果。

更多可信、相关、可比信息通常减少未知；更多重复/偏差信息不会自动提升准确性。新反证可以降低优先级或撤销推荐，这属于正常更新。
