# Codex 开发启动提示词

## 首次启动提示词（完整复制给Codex）
你正在开发“游探/锦鲤云 IAA 产品情报系统”。本目录是已与业务负责人对齐的开发交接基线。
先读取README.md，再按序读docs/01～08、contracts/schema.sql、contracts/ai-extraction.schema.json；检查当前仓库和AGENTS.md。不要直接把reference/prototype的补丁式JS改造成生产工程。

已确认：Java+MySQL后台和Web；微信/抖音/iOS中国、Google Play美国/英国/德国/法国；每日优先Top100；纯IAA有证据且满足市场门槛自动入库；每周5～10精选；多人选用简单填报。产品统一、平台版本独立、榜单名次不综合；可指定日期且缺失不能回填；热度和买量分开。

请先完成P0及能独立开展的P1：
1. 给出需求追踪矩阵和阶段计划，区分已确认、建议默认值和外部阻塞。核实API/DDL一致性。
2. 检查现有工程可复用项。无工程则采用交接包建议栈；版本锁定，按官方资料核实兼容性。
3. 完成工程骨架、MySQL迁移、开发seed和产品库/榜单/选用的端到端最小闭环；优先验证跨平台一行、日期快照、缺失状态和多人记录。
4. 先以可重复且明确标识的模拟数据完成测试，同时验证可访问的真实来源；缺凭据或付费权限时给出精确缺口，继续完成其余工作。不虚构接口、纯IAA证据和试采结果，不自动购买数据。
5. 页面按reference蓝白紧凑后台风格；二级菜单：实际使用（产品库、榜单观察、每周精选、选用记录），配置管理（AI采集中心、规则配置）。
6. AI做授权数据提取、玩法分类、证据定位与周报文案；Java做调度、校验、去重、快照及确定性规则。模型输出必须通过Schema和业务校验；证据不足保持待识别。
7. 参考docs/07执行有业务价值的检查。每阶段更新README、环境变量模板、启动说明、迁移说明和完成矩阵，报告实际执行的测试与尚未真实验证部分。
不要把未经实现的页面按钮或演示数据称为正式功能；不要把原型部署地址当作Java运行环境。除必须由业务负责人决定的范围变化/外部购买外，按已确认方向持续推进，不反复询问已确认需求。

## 后续阶段提示词
