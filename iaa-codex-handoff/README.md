# 游探 / 锦鲤云 IAA 产品情报系统 — Codex 开发交接包
版本：v1.0 · 2026-10-27 · 阶段：需求基线与开发设计交接

目标：每天发现市场验证过的纯 IAA 休闲游戏，自动积累可追溯的产品库，帮助叶工、杨灵芝及其他使用者选题；每周输出 5～10 款精选。

## 如何交给 Codex
1. 将本目录解压到新项目根目录；先打开 `START_CODEX.md`，把其中“首次启动提示词”发给 Codex。
2. Codex 按入口文档阅读，不从原型 JS 直接拼接生产系统。先完成真实数据源验证和契约，再分阶段开发。
3. 数据源账号、模型密钥通过服务端环境变量或密钥管理配置；不要写进文档、前端或 Git。
4. 没有真实凭据仍能完成本地开发与样本测试，但不得宣称真实采集、IAA 确认或定时周报已经运行。

## 原型与正式需求的关系
在线原型：https://iaa-radar-product-lab.mochao1009.chatgpt.site
风格：锦鲤云蓝白数据后台、白顶栏、二级左侧菜单、密集表格、抽屉详情。
原型使用虚构样本、固定日期、localStorage；没有 Java/MySQL、真实采集、模型调用或多人同步。
**跨平台产品归集已在讨论中确认，但原型尚未完成该改造。正式开发必须按本包实现产品统一、版本分平台、排名分榜单。**
原型的多层函数覆盖、日期补丁、固定统计和样本公式不能作为生产实现方案。

## 需求优先级
会话中用户明确确认 > 本包已确认需求 > 本包建议默认值 > 原型演示代码。
遇到矛盾先写清影响；不要为了省开发量取消跨平台、历史快照或数据可追溯性。
本包是交接设计，不是已通过供应商验证的采集承诺。DDL、API 和阈值是建议实现基线，可在不改变业务语义的前提下细化。
