# 外部信息采集边界

本目录是独立 Java 21 Maven 模块，本会话的实现范围限于外部信息抓取。

2026-11-02 用户授权实际抓取与必要数据库扩展：数据库适配、迁移和运行API放在后端 `collection.capture` 包及相应迁移中；依赖方向仅为后端适配层 → 本目录。本目录仍保持无数据库/业务依赖。真实抓取验证和仅采集数据的数据库写入属于本次授权范围。

- 允许：来源获取、材料接收、确定性解析、来源范围校验、证据留存、覆盖计算、文件导出。
- 禁止依赖 `backend`、Spring、JDBC、产品库、规则、选用、周报、前端或部署脚本。
- 对外只交付来源观察与原始材料，不返回内部 productId/versionId/snapshotId，不执行业务入库。
- 新来源实现 `SourceAdapter`；新获取方式实现 `MaterialFetcher`；新输出实现 `CaptureSink`。
- 不推断 IAA、收入、增长、身份合并；未知来源日期留空，不以采集时间补齐。
- 微信真实客户端与引力引擎网页是不同来源，不能互相冒充。UI 采集遵循对应技能，界面证据先独立导出。
- 测试使用本地材料或假传输，不连接生产数据库，不部署，不自动启用定时任务。
