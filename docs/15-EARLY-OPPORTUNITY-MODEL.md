# 早期机会组合与新增数据计划

生效设计：2026-11-03；来源规则 capture-research-leads-2.0.0，产品内 Skill market-weekly-2.3.0。正式资格仍使用 V2.2 六维范围，不把来源研究线索改称纯IAA推荐。

## 目标与配额

先发现可验证的差异化机会，再决定是否投入；成熟市场仅作为需求和玩法基准，不默认推荐复刻。

| 分组 | 核心比例 / 名额 | 用途 |
|---|---|---|
| 成熟基准 | 50% / 最多2 | 理解已被验证的需求、设计与市场约束；正式精选优先占用该组 |
| 新入榜机会 | 25% / 最多1 | 发现刚进入当前来源榜单、正在上涨的候选 |
| 单榜加速机会 | 25% / 最多1 | 发现近期入榜后开始加速的候选，与新入榜组按年龄互斥 |
| 额外早期研究 | 最多1 | 增补上述两类符合证据的机会；不作成熟热门补位 |

50/25/25指核心4席的研究预算，不是要求每期实际占比相同，更不是投资比例或成功概率。合计最多5项，不足留空。先分配两类早期席，再分配基准和额外席；同来源/平台/市场身份去重，来源玩法标签最多2项。正式项与来源同平台同名保守避重（不据此合并产品）；资格评估结果保留，超出基准席仅改变当期展示选择。

## 入场规则与证据

查询28个自然日、材料采集时间及可用时间均不晚于冻结截止。每个来源/平台/地区/榜单/解析器版本/日期只取最新采集观察；较新的部分观察不能借用旧快照。查询不排序大JSON，Java按稳定键排序。

1. **可证明的来源内新入榜**：28日窗口最早出现日前连续3天均为同口径完整Top100，未出现同来源ID或同名同发行方标签。此前缺采、只有部分榜单、解析器变化不能充当未入榜。此结论仍不能证明历史从未入榜、首次上线；改名和发行方变化须补证。
2. **新入榜组**：距首次观察1—3天，入榜后连续至少2天；真实首末排名上升至少10名、最新日继续上涨。榜外不赋101名，不虚构入榜涨幅。
3. **单榜加速组**：首次观察4—14天；同样满足入榜基线，最近3天连续；两日上涨≥15名、最新日上涨比前日多≥5名、前日未跌；至少5个同榜可比候选，两日涨幅前20%。并列按稳定键排序；保存两次日涨幅、加速度、同榜序号与分母，不跨榜比较总分。
4. **重返/断档**：28日已有更早记录，当前连续段晚于首次记录，保持回归状态，不能进新增组；缺采与真实退榜尚未区分时按同样保守处理。
5. **来源研究资格**：截止日有记录、来源明确轻度玩法标签或描述，同来源畅销信号先排除补证。无appid保留身份待核；空发行方不拼跨日。宣传DAU、买量信号不能视为真实自然增长或IAA证据。
6. **基准组**：至少5/7天且最近3天连续；当前Top20，或首末上涨≥10且进入Top50。展示最新回落及其他需求榜走势；此组不宣称新增机会。
7. **排队**：早期组每榜按两日涨幅、当前名次、稳定键排序；基准组沿用7日上升优先、观察天数、当前名次排序；跨榜按稳定榜单键轮转，避免假装跨榜涨幅可比。保留所有候选未选原因。

三个例子：第一次抓到某游戏第3名→新旧未知；完整榜单连续3天未出现，之后75→58→新入榜研究线索；入榜第5天，最近90→85→65，同榜6个可比样本中增幅第1→单榜加速研究线索。最后一个也只能证明榜单加速，不能证明用户增长或新赛道。

## 从游戏信号到玩法机会

当前自动输出的是**早期榜单研究机会**，不是自动证明新赛道。全部 noveltyStatus=UNVERIFIED，展示调查假设与24—48小时行动：核实appid/首发日期，录制前5—10分钟核心循环，找至少3款近似竞品做操作/目标/失败条件/关卡规则/变现差异表，再决定是否制作差异化原型。宽泛消除/塔防分类不能代替机制级创新判断。

AI可整理来源描述、视频人工摘录、竞品对照中的可引用事实与待验证假设；不得直接宣布玩法首创、自然增长或纯IAA。当前自动报告使用Java确定性模板，未调用模型生成新市场事实。

## 需补充的数据（按优先级）

| 优先级 | 数据内容 | 实际获取路径 / 缺口 | 支持判断 |
|---|---|---|---|
| P0 | 28—60天完整同榜Top100，条件允许Top500，日期、采集时间、完整度 | 现有服务器每日积累；历史回采受来源可访问范围约束；目前不足28日 | 排除首次采到、回归、缺采；缩短发现延迟 |
| P0 | appid、发行方、首发日期、版本更新、改名 | 官方详情/发行方材料；目前微信抖音来源缺稳定appid | 真新游戏还是旧游戏改名/重发 |
| P0 | 实机核心循环、关卡机制、广告/内购入口、3款近似竞品差异 | 人工试玩留证，AI整理后人工复核 | 新玩法、差异化可行性、版本IAA |
| P1 | 同口径新增、DAU、留存；曝光、素材量、投放起始、达人活动 | 发行方授权分析或具体数据服务字段；未接入，不自动购买 | 自然需求还是买量拉榜 |
| P1 | 同机制竞品数量、新进入者、发行方数量、集中度、范围边界 | 先建实机复核的机制/竞品库 | 样本内拥挤度、玩法扩散；仍非全市场空白证明 |
| P1 | 推荐后7/14/28日排名和退出/缺采、人工结论、原型成本结果 | 冻结周报+持续日快照+研究结果登记 | 时间外回测提前量、误报与持续性 |

优先积累已有来源历史和补实机/身份，不必先购买全部平台。任何付费采购应先拿字段样例与更新频率，核对历史深度、平台覆盖、保存与内部分析权限；只有排名的数据源不能补足用户增长和留存。海外缺失不阻断国内，但不能推断海外没有机会。

## 快照、运行与升级

沿用现有每次服务器采集完成后的报告桥生成修订，因此日内可查看新机会，无需等周末；每期保留业务期、可用截止、28日边界、Skill哈希、规则、组合配额/缺席原因、候选审计、入榜基线材料ID/哈希、同榜分母与数据需求。相同输入复用，新增输入新修订，旧报告仅读冻结内容；旧报告没有新字段时保持旧展示。

没有新增数据库表/列，本轮不新增Flyway迁移、不改旧迁移。沿用V15的JSON快照；环境变量无需新增。启动仍为根目录mvn package、frontend构建、正常Java/systemd运行。部署先JDBC备份，在新目录放置JAR与dist，停止采集再切current，恢复Web与采集/报告服务。

阈值是建议默认值，尚未通过时间外回测。比例、最多5项、强调新机会是已确认方向；28日、3日基线、10/15/5名阈值、前20%和最小样本5为可审计的初始实现默认值。真实市场新颖性、身份与用户增长数据属于外部缺口。

现有抖音新游榜纳入同来源背景证据，`hasSourceNewGameSignal`表示匹配新游分类；它不是独立需求榜、不替代此前完整未出现证据，也不证明真实首发或新玩法。
