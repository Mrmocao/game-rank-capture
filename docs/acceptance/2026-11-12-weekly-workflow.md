# 每周精选研发交付与规则复盘验收（2026-11-12）

## 完成内容

- V24 新增 `weekly_report_delivery`：周一生成研发交付包，记录接收团队、状态、接收人和备注。
- V24 新增 `weekly_report_review`：周五生成上周规则总结、结果统计、证据缺口和迭代建议。
- 周一任务仍按北京时间 09:00 生成周报；周报成功后自动创建交付包。
- 周五任务按北京时间 17:00 读取上一个自然周的唯一周报并生成复盘。
- 每周精选页面增加交付/复盘状态区；支持生成/刷新、Markdown 下载、研发接收确认和复盘预览。
- 交付包与复盘使用确定性 Java 规则生成，不自动向外部聊天工具发消息；原报告、榜单材料和输入哈希保持冻结。

## 当前机制

核心席位为成熟基准 2、严格新入榜 1、严格单榜加速 1；严格席不足时研究补位到最多 5 项。研究补位需要连续观察、同榜热度或增势证据，缺失日期不回填；纯 IAA、玩法、身份和版本证据独立核验。不同榜单名次不合并，统一产品关联后展示跨平台证据卡。
