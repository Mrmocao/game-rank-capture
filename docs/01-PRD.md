# 01 产品需求与业务规则

## 1. 目标与边界
核心是生产选题参考：发现市场信号 → 识别纯 IAA → 规则入库 → 产品挑选 → 简单记录制作状态 → 周报。
市场验证指榜单、持续表现、增长及可获取评价等信号，不等同盈利证明，也不承诺复刻后的商业收益。
首期不做制作审批、排期、人力绩效、预算、开发任务管理或重型项目管理。不自动采集源码、复制美术或生成换皮工程。

## 2. 已确认范围
| 项目 | 口径 |
| --- | --- |
| 国内 | 微信小游戏、抖音小游戏、中国区 iOS |
| Google Play | 美国、英国、德国、法国，按国家独立记录；不设大陆 Google Play 榜单 |
| 类型 | 休闲游戏；正式库仅纯广告变现 IAA |
| 数据频率 | 每日，优先目标榜单前 100；按来源实际覆盖标明缺口 |
| 数据源 | 可付费；购买与预算另行确定 |
| 历史 | 从上线起持续积累；已有历史可补，不阻塞启动 |
| 自动入库 | 纯 IAA 有依据，且命中市场表现条件，无强制审批 |
| 周报 | 每周 5～10 款精选；不足时少出，不凑数 |
| 内容 | 玩法简述、类型标签、截图或视频原始入口 |
| 选用 | 同一产品可多人选用，记录独立维护 |
| 人工修正 | 可补介绍、改标签、纠正 IAA、排除项目，采集不覆盖人工修正 |

## 3. 核心规则
### BR-01 产品和平台版本
统一产品代表经确认的同一游戏；平台版本承载 appid、包名、商店 ID、入口和变现证据。
同名不是合并依据。同玩法/相似换皮不是同一产品。无法确认时分别保存；提供关联、合并和撤销能力。
同一产品微信版纯 IAA、iOS 版混变时，仅微信版本是合格参考版本；iOS 排名可显示为关联参考，不能因此把它标成纯 IAA。

### BR-02 榜单独立
排名身份 = 数据源 + 平台 + 地区 + 榜单 + 分类 + 设备口径 + 统计日期。
玩家热度与买量分别保存。免费榜、畅销榜、热度榜保留各自原始名称、指标和解释。
不跨平台平均名次，不用最好名次代表综合名次，不直接把投放强度作为成功依据。
畅销榜是内购收入相关线索，不能作为纯 IAA 成功条件；用于识别冲突、参考或排除。不同来源同名榜单也不能静默拼接。

### BR-03 识别与入库
每个平台版本的 IAA 状态：UNKNOWN（待识别）、PURE_IAA、MIXED、IAP、OTHER。
PURE_IAA 必须有有效来源和明确判定依据；免费、含广告、未发现内购、集成广告 SDK 或模型置信度均不足以单独确认。
优先依据：平台/发行方对该版本的明确分类、可信授权数据源的变现分类，或有留存依据的人工实测确认。记录版本、范围、观察时间、原文/截图位置和判定方式；冲突证据需保留。
有效证据与冲突处理由可配置策略决定；缺少证据保持待识别，不让模型“补全”。
产品状态：PENDING_IDENTIFICATION（无已确认纯 IAA 版本）、OBSERVING（有纯 IAA 版本但未达市场门槛）、FORMAL（至少一个版本同时满足纯 IAA 和市场条件）、EXCLUDED（人工排除）。有混变版本但另有合格版本可正式入库。
所有识别状态及候选均可检索，默认展示全部并标明分类；正式推荐只选合格产品。
规则命中记录必须关联证据、快照、规则版本，给出可读理由。规则变更不覆盖历史决定。
已入库产品短期掉榜不删除；新发现变现冲突时重新评估正式资格，保留状态历史，暂停正式推荐。人工排除优先且可撤销。

### BR-04 市场信号
- NEW_OBSERVED：首次被系统观察到进入目标榜单，先观察，不等同真实新游。
- RAPID_RISE：同榜单、同地区、相同来源口径下可比较快照的名次提升。
- SUSTAINED：指定窗口内达到有效在榜天数和排名要求。
新进榜不单独触发正式入库；纯 IAA + RAPID_RISE/SUSTAINED 可以。
初始建议、待真实样本校准：持续表现=最近14个自然日内至少10个有效日在前50；快速上涨=7天前与当日同榜快照均有效，提升≥20名且当日进入前50。均为配置，不是用户确认的固定门槛。
缺失日不算未上榜；覆盖不完整不判定跌出榜单；窗口不足标记数据不足。没有7天前快照不改用任意较近日期伪称7日增长。
Top100之外是“未出现在该覆盖范围”，不是第101名。首次采集日所有存量均可能首次观察，需标记初始化批次，不把它们全部当作周报新品。

### BR-05 选用
一条选用记录：产品、可选参考平台版本、负责人自由填写、状态、选用/开始/完成日期、备注、创建/修改人和时间。
状态为已选、制作中、已完成、放弃，无审批。产品“未选”是没有记录的派生状态，不落成产品单一状态字段。
同一产品允许同一/不同负责人多条记录，无唯一占用锁。制作状态不改变产品市场资格。
时间顺序合法；状态可手动调整，允许补填日期，不强制依次流转；状态变更保留审计。

### BR-06 周报
每周独立生成并留存版本。精选综合新发现、上涨、持续表现，说明平台版本和原始依据；新发现未达门槛可作为“观察提醒”另列，不充当正式精选。
对同一产品跨平台去重；已制作中/已完成默认不占推荐挑选名额，但出现明显增长可列“已关注项目动态”；放弃不等同永久排除。
无足够合格产品时显示实际数量和原因。数据不全或任务失败时展示覆盖/完整性提示，不能输出“本周无机会”的伪结论。
默认 Web 查看历史并可导出，不做消息推送，不把本需求自动配置为 ChatGPT 自动化。
